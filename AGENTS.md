# AGENTS.md — pg-lo

Guidance for agents working in this repo. Read this and `README.md` first.

## What this is

Minimal, typed wrapper for **PostgreSQL Large Objects** (`pg_largeobject`) with
streaming + a filesystem cache. ESM-only, TypeScript strict, zero dependencies
beyond `pg` (peer). ISC license. Repository:
https://github.com/rayenboussayed/pg-lo

## Requirements

- Consumer floor: Node `>=18`, PostgreSQL `>=14` (tested on `postgres:18`),
  `pg ^8.23`.
- Development floor: Node `>=22.17.0` (mdaics renders docs in `npm run docs`).
- e2e tests need a real PostgreSQL on `DATABASE_URL` (see `tests/e2e`); unit
  tests are mocked and need nothing.

## Commands

```bash
npm test               # vitest run (watch mode: npm run test:watch)
npm run test:unit      # mocked unit tests
npm run test:e2e       # real Postgres — DATABASE_URL required
npm run test:coverage  # vitest run --coverage
npm run typecheck      # tsc --noEmit
npm run build          # tsc && node --check dist/index.js
npm run docs           # build + mdaics -> docs/ (committed)
```

## Invariants — do not break

- **Transaction discipline.** All `lo_*` operations must run inside
  `BEGIN`/`COMMIT`. `createFromStream` and `openReadableStream` cache hits read
  from `tmpDir` without touching the DB; cache misses do.
- `createPgLo` accepts a connected `pg.Client` **or** `pg.Pool` (since 1.0.1).
- `tmpDir` defaults to `<cwd>/tmp/pg-lo`; entries there are the filesystem cache
  — do not commit it (gitignored).
- Large-object handles auto-close on stream end; `lo_close` is not optional
  housekeeping, it is part of the API contract.
- `tee()` (`src/utils.ts:24`) splits a Readable into two PassThrough branches
  with backpressure/abort handling — it is load-bearing for the
  write-through-cache path; keep error and `end` forwarding exact.
- `unlink` removes the cache entry too; a stale `tmpDir/<oid>` would shadow a
  live oid after `lo_unlink`.

## Docs

`docs/*.md` are generated by mdaics from TSDoc in `src/` — never hand-edit.
After changing `src/`, run `npm run docs` and commit the regenerated files;
`git diff --exit-code docs/` must be clean before you commit.
